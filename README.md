# BLine Web

Phase 1 implementation repo for the web-first BLine editor.

## Scripts

- `npm run lint`
- `npm run typecheck`
- `npm run test`
- `npm run test:e2e`
- `npm run build`
- `npm run tauri:dev`
- `npm run tauri:build`

Systemcore service/package work is intentionally placeholder-only until Phase 3.
